# Java foundations build 17: above-average count

Course: Java Level 1
Module: Java foundations build 17

Complete a two-pass List-processing method that counts how many values are above the average. The project reinforces decomposing a calculation into passes, integer-to-double conversion, empty-list handling, and explaining why a second loop is useful.

Requirements:
- Implement `computeScore(List<Integer> values)`.
- Return `0` for an empty list.
- First compute the total and average.
- Then count how many values are greater than the average.
- Verify the default case by hand: average is `7.0`, and `8` and `13` are above average, so the result is `2`.

Quick run hint: `javac Main.java && java Main`
