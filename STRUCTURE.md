# Java-Level-1 Structure

This repository is a legacy Java direct-source bank with some generated support
folders. It backs `Java Level 1`, `Java with Graphics`, `Java without Graphics`,
and bridge course links.

Top-level project folders are active when they are linked by the live catalog.
The `graphics/` and `src/` directories are support/source roots, not separate
public projects.

New material should avoid creating unlinked top-level variants. Prefer either
the existing direct-source convention for legacy exercises or a linked wrapper
with `README.md`, `starter/`, and `solution/`.
