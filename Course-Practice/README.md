# Java Level 1 practice files

Each starter opens an independent attempt. The matching solution is for instructor review. Some original solutions remain in their existing project folders. For console work, compile the selected Main.java with JDK 21 and run Main. For drawing projects, run Main and open drawing.png in the working directory.

The original Juni project files remain at their historical paths. The drawing exercises adapt their coordinates and Java drawing operations to a standard JDK image surface. The first grid check-in uses the one-based ten-by-ten example in the student outline.
