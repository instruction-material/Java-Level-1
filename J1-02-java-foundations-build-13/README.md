# Java foundations build 13: even-value scoring

Course: Java Level 1
Module: Java foundations build 13

Complete a small List-processing method that adds only the even values in a list of integers. The project reinforces enhanced `for` loops, `%` divisibility checks, accumulator variables, and checking output against a hand-computed example.

Requirements:
- Implement `computeScore(List<Integer> values)`.
- Add a value to the total only when it is even.
- Leave odd values out of the score without changing the list.
- Verify the default case by hand: `2 + 8 = 10`.
- Add one custom case, such as an all-odd list or a list containing zero.

Quick run hint: `javac Main.java && java Main`
